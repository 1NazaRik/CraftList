# CraftList

Клиентский мод для Minecraft: закрепляй рецепты из открытой книги рецептов и смотри, сколько материалов уже есть в инвентаре.

## Использование

1. Открой книгу рецептов, чтобы Minecraft синхронизировал известные рецепты.
2. Нажми **K** (клавишу можно переназначить в настройках управления).
3. Найди предмет и нажми на рецепт. Кнопками **+** и **−** настрой количество.
4. Список материалов появится в HUD. Задачи хранятся в `config/craftlist.json`.

Мод работает только на клиенте и не требует установки на сервере.

## Сборка из исходников

Нужны JDK 25 и Fabric Loom. Запусти `gradlew.bat build`; готовый мод появится в `build/libs`.
